# Pocket 3 MCP — 設計約定

2026-09-07，依使用者本輪修正。

產品名稱統一為 **Pocket 3 MCP**：原生 macOS 相機觀察 App，內含本機 AI、MCP 與 CLI。Bridge 是早期工程名稱；保留既有 bundle identifier 與私有快取路徑作相容用途，避免名稱變更造成既有設定和模型下載遺失。產品介面、更新、檔案及 MCP server 名稱不再使用 Bridge。

## 共用的是美感與通用 App 行為

YunDesign 的色彩、字級、圓角、描邊按鈕、卡片、選擇器、膠囊狀態列、提示列、外觀設定及圖標不另行設計。

設定視窗、更新檢查、選單列的左右鍵操作、視窗記憶、Dock、登入啟動、關於、權限和回報問題，沿用 YunAudio 的通用行為，將內容換成相機用途。

## 改的是內容與必要的版面配置

- 底部仍使用原版 `YunStatusPill`／`YunWrap`。只顯示相機連線、實際格式／FPS、AI 存取權、執行中任務和 MCP 服務狀態。
- 不把音量、音訊路由、LUFS、音高或虛擬音效卡狀態放入相機產品。
- 不把膠囊列改成另一種分區工具列；不自行增添分隔線、全寬提示外框或放大內距。
- Camera 畫面、AI 問答及診斷的內容依需求安排，但每個控件維持既有尺寸和密度。
- 長文字應換行、截斷並提供完整內容，或放入可捲動容器；不能將其他控件擠出視窗。

## 可量測的基準

- 主視窗最小外框 1180×720 pt，左欄 268 pt、右欄 360 pt、欄距 16 pt、左右邊距 24 pt。
- 卡片預設內距 12 pt；設定側欄 168 pt；小按鈕使用 YunButtonStyle 原有尺寸。
- 提示列完全沿用 `YunAudio/MainWindow.errorBanner`：圖示 11 pt、caption 字級、水平內距 12 pt、垂直內距 8 pt、文字 1 行。不要在列內放入會撐高行高的額外按鈕。
- 淺／深色、短／長訊息、中文／英文、主視窗最小尺寸、設定窄尺寸都必須驗證。

畫面擷取使用 AppKit 真實視窗的 theme frame；相機 video layer 以當次新影格代入。這可檢查標題列與裁切，但不是 WindowServer 螢幕截圖。
