# Interface screenshots

These nine images show the current beta 2 development interface (build 11).
The published beta 1 download is build 9. The gallery is labelled separately
from release verification and is not evidence that beta 1 contains later fixes.

The App's UI capture path detaches the live preview view and omits sensor image
encoding. The camera may be connected to demonstrate available controls, but no
Pocket 3 photograph is included. The MCP example uses the standard Applications
path, with no private workspace path.

[Capture metadata and SHA-256](manifest.json) records the actual App binary and
each English, Traditional Chinese and Simplified Chinese image. UI screenshots
are kept separately from private hardware evidence under ignored `artifacts/`.
